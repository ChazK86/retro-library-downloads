## Release notes

[Windows and Android notes](https://github.com/ChazK86/retro-library-downloads/releases/tag/protected-source-2026-11-04) · [Linux notes and installation](https://github.com/ChazK86/retro-library-downloads/releases/tag/linux-protected-v1.0.1)

Windows is unsigned. Android uses a development signing certificate. Linux packages are unsigned previews, not Flathub submissions, and require Freedesktop Platform 25.08. The ARM64 Flatpak requires compatible Linux; Android uses the APK. Physical Linux phone testing has not been performed for this release.

Original source addresses stay on the server; public apps carry encrypted download capabilities without their decryption key. Selected downloads, local installation and local removal remain available. This protects source addresses from package extraction, rather than preventing redistribution of downloaded content.

Game images, console firmware, personal saves and account credentials are not bundled. Use content you have permission to use.
